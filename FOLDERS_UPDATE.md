# Пользовательские папки конспектов

## Что изменено

- Готовых названий предметов и папок нет.
- Каждый пользователь создаёт собственные папки.
- Каждая папка отображается отдельной кнопкой в боковой панели.
- Перед сохранением нового конспекта пользователь выбирает папку.
- Новую папку можно создать прямо в форме сохранения.
- Уже сохранённый конспект можно переместить в другую папку.
- Сохранённый конспект можно одновременно отредактировать и переназначить.
- Папку можно переименовать или удалить.
- При удалении папки конспекты не удаляются, а переходят в «Без папки».

## Обязательный шаг

В Supabase SQL Editor выполните файл:

```text
sql/add_user_folders.sql
```

Без миграции приложение не сможет создавать папки и сохранять `folder_id`.
