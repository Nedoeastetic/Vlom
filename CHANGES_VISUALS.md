- `ui/ai_analysis.py` — добавлен строгий промпт для таблиц и графиков.
- `ui/text_editor.py` — визуализации отображаются отдельно, а при редактировании сохраняются.

## Новый файл

- `services/visualization_service.py` — валидирует JSON-блоки и строит таблицы/графики.

## Форматы ответа ИИ

Таблица:

```vlom-table
{
  "title": "Название",
  "description": "Описание",
  "columns": ["A", "B"],
  "rows": [["x", "y"]]
}
```

График:

```vlom-chart
{
  "title": "Название",
  "description": "Описание и единица измерения",
  "type": "bar",
  "x": "Категория",
  "y": "Значение",
  "data": [
    {"Категория": "A", "Значение": 10},
    {"Категория": "B", "Значение": 20}
  ]
}
```

График создаётся только при наличии как минимум двух точных числовых значений в источнике. Это снижает риск выдуманных данных, но важные значения всё равно следует проверять по исходному материалу.
