# Исправление папок и переноса конспектов

## Заменить файлы

- `db/user_manager.py`
- `ui/notes_view.py`

## Выполнить SQL

В Supabase → SQL Editor выполните целиком:

- `sql/fix_folder_permissions.sql`

Скрипт сохраняет существующие данные, выдаёт права роли `authenticated`,
восстанавливает RLS-политики и обновляет schema cache PostgREST.

## Что исправлено

- операции больше не считаются неуспешными только из-за пустого `response.data`;
- создание папки проверяется повторным `SELECT`;
- перенос проверяется чтением обновлённого `folder_id`;
- после создания папка сразу выбирается и показывается;
- после переноса открывается целевая папка;
- добавлена кнопка «Обновить папки»;
- реальные ошибки Supabase показываются в интерфейсе;
- при выборе той же папки выводится понятное сообщение.
